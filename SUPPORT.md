# Support

Testra is a self-service reference. Issue reporting, pull requests, feature requests, and contributions are closed.

- Start with the [runnable search example](docs/samples.md#run-the-goblin-race) to check your Playwright setup.
- Use the [setup guide](docs/playwright-setup.md) to make the skills visible to your agent and run a test from an application repository.
- Use [frontend diagnostics](docs/frontend-diagnostics.md) to interpret failures and the [skill catalog](docs/regression-skills.md) to choose a check.

For questions about the tools themselves, use the official [Playwright documentation](https://playwright.dev/docs/intro) or your agent's documentation.
